# 계산 근거

TankStruct v0.1.0은 상압 액체 저장탱크의 개념·견적 단계에서 설계안을 비교하는 스크리닝 도구입니다. 실제 유한요소해석(FEA), 적용 규격 계산서, 제작 승인서가 아닙니다.

## 1. 적용 범위

- 대기와 통하는 개방형 또는 통기형 탱크
- 정적인 액체 정수압
- 사각 탱크의 판 두께·보강 격자 비교
- 원통 탱크의 바닥 최대 둘레응력 확인
- 호퍼 탱크의 용량 계산과 수직 측판 참고 검토

밀폐·가압·진공, 지진, 풍하중, 운반, 교반기, 배관·노즐 하중, 지지 다리, 열구배, 좌굴, 피로수명, 용접부 상세, 기초 침하는 계산하지 않습니다.

## 2. 정수압

액면에서 깊이 `h`인 곳의 게이지 압력은 다음과 같습니다.

`p = ρgh`

- `ρ`: 액체 밀도 `비중 × 1,000 kg/m³`
- `g`: 표준중력 `9.80665 m/s²`
- `h`: 액체 높이 `m`

벽 1 m 폭에 작용하는 합력은 `F = ρgH²/2`, 작용점은 바닥에서 `H/3`입니다.

## 3. 사각 탱크

입력한 수평·수직 보강재와 바닥·코너·연속 상부 프레임이 각 패널 가장자리를 지지한다고 가정합니다. 가장 긴 벽의 패널을 만들고, 패널의 짧은 변을 지배 스팬 `s`로 사용합니다.

각 패널을 바닥 최대 수압 `p`가 전 구간에 작용하는 1 m 폭의 단순지지 스트립으로 단순화합니다.

- 최대 굽힘응력: `σ = 0.75ps²/t²`
- 최대 변형: `δ = 5ps⁴/(32Et³)`

실제 2방향 판 작용의 유리한 효과는 반영하지 않았지만, 지지 조건 자체가 불확실하면 이 근사도 안전측이라고 보장할 수 없습니다. 상부 프레임이 없거나 보강재가 패널 경계로 작동하지 않으면 모델을 적용하지 않습니다.

첨부된 `사각_tank 강도계산 (1).pdf`에는 수압을 받는 직사각형 탱크의 판 두께, 수직·수평 보강, tie-rod 예제가 있습니다. 해당 자료의 `α` 도표는 출처·판본·적용 경계조건을 완전히 추적할 수 없어 v0.1.0 계산식으로 직접 전사하지 않았습니다. 대신 가정이 화면에 드러나는 단순 스트립 모델을 사용했습니다.

## 4. 원통 탱크

바닥 최대 정수압을 사용한 얇은막 둘레응력만 계산합니다.

`σh = pD/(2t)`

원통의 변형, 상부 풍좌굴, 지붕·바닥 접합부, 앵커, 지진, 진공 좌굴은 계산하지 않습니다. `t/D`가 얇은막 가정에 맞는지도 결과의 계산 과정에서 확인합니다.

## 5. 보강재 요구 단면계수

보강재를 단순지지 보로 보고, 패널의 바닥 최대 수압과 지배 면적을 선하중으로 바꿉니다.

- 최대 모멘트: `M = wL²/8`
- 요구 단면계수: `Zreq = M/σallow`

이 값은 프로파일을 고르는 출발점입니다. 실제 프로파일의 국부좌굴, 비틀림, 코너 연속성, 용접 크기와 용접부 강도는 별도 계산해야 합니다.

## 6. 재료와 허용응력

`허용응력 = 기준강도 × 장기하중계수 × 이음효율 × 온도감소계수 ÷ 안전계수`

SUS 프리셋의 기준강도는 상온 0.2% 내력 대표값입니다. PP-H는 단기 강도를 그대로 설계강도로 쓰지 않도록 내부 장기하중 감소계수를 적용하지만, 이는 DVS 2205의 온도·수명·약품별 장기강도 계산을 대신하지 않습니다. 사용자는 밀시트와 공급사 자료로 모든 물성값을 바꿀 수 있습니다.

## 7. v0.2.0 보강재 실제 단면계수 검증

요구 단면계수를 제시하는 데서 끝내지 않고 사용자가 프로파일 표에서 확인한 실제 단면계수와 비교합니다.

`U_Z = Z_required / Z_actual`

- 수평·수직 보강재마다 요구 Z, 입력 Z, 사용률을 따로 표시합니다.
- 보강재가 있는데 실제 Z를 입력하지 않으면 스크리닝 통과 판정을 내리지 않습니다.
- 프로파일 방향, 국부좌굴, 비틀림, 용접과 코너 연속성은 별도 검토합니다.

## 8. 재검증 계산서

화면과 CSV, PNG, PDF는 동일한 계산 감사 추적을 사용합니다. 각 행은 `구분 → 항목 → 공식 → 입력값 대입 → 결과·단위 → 근거` 순서로 기록합니다. 보고서는 프로젝트명, 생성시각, 전체 입력, 판정, 경고도 함께 저장합니다.

## 9. 최적화의 뜻

표준 두께 후보와 수평 보강 0~4줄, 면당 수직 보강 0~3개를 조합해 응력·변형 사용률이 모두 100% 이하인 안을 찾습니다.

- 균형안: 판재 중량과 제작 복잡도를 함께 낮춘 내부 점수
- 제작 단순안: 보강 개수가 적은 안 우선
- 판재 경량안: 측판·바닥판 추정 중량이 낮은 안 우선

보강재 자체 중량, 재료 단가, 용접 길이별 공수, 검사 비용은 입력하지 않으므로 “최저 비용”이라고 표현하지 않습니다.

- [Outokumpu 오스테나이트계 재료표](https://www.outokumpu.com/-/media/files/industries/documents/outokumpu-enhanced-structural-efficiency-with-duplex-stainless-steel-in-pressure-vessels.pdf): 304·316·316L의 상온 최소 내력과 설계응력 예시 확인
