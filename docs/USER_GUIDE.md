# 사용 설명서

## 빠른 시작

1. 프로젝트명과 탱크 형상을 선택합니다.
2. 내부 치수와 실제 액체 높이를 mm로 입력합니다.
3. 액체 비중과 설계온도를 입력합니다.
4. 재료를 고르고 `재료 물성·감소계수 직접 확인`을 펼쳐 값을 확인합니다.
5. 현재 생각한 판 두께, 수평·수직 보강 수, 안전계수와 허용 변형을 입력합니다.
6. `현재 제작안 검토`를 누릅니다.
7. 응력 사용률, 변형, 경고와 비교안을 함께 봅니다.

## 결과 읽는 법

- `입력한 단순 모델 범위에서는 목표 조건 이내`: 근사식의 응력·변형 사용률이 100% 이하라는 뜻입니다. 제작 승인이 아닙니다.
- `추가 검토 또는 설계 변경 필요`: 응력·변형 초과, 밀폐 조건, 호퍼 제외 영역 등으로 통과 판정을 내릴 수 없다는 뜻입니다.
- `근거 신뢰도`: 재료와 형상에 필요한 자료가 얼마나 확보됐는지 보여줍니다. 구조 안전확률이 아닙니다.
- `요구 단면계수 Z`: 보강 프로파일을 고르기 위한 최소 출발값입니다. 프로파일 제조사 표의 축 방향을 맞춰 비교하고 용접·좌굴을 추가 검토해야 합니다.

## 저장과 이동

- 입력값은 현재 브라우저의 `localStorage`에 자동 저장됩니다.
- `JSON 백업`은 입력값과 재료 수정값을 파일로 저장합니다.
- 입력 패널의 `JSON 불러오기`로 같은 형식의 파일을 복원합니다.
- `CSV 결과`는 현재 결과 요약을 UTF-8 BOM CSV로 저장합니다. Excel에서 열 수 있지만 실제 `.xlsx` 파일은 아닙니다.
- 서버 계정이나 데이터베이스가 없으므로 다른 PC와 자동 동기화되지 않습니다.

## 로컬 실행

`data/materials.json`을 읽어야 하므로 `index.html`을 파일로 직접 열지 말고 간단한 로컬 서버를 사용합니다.

```powershell
cd tank-structure-screening
python -m http.server 4174
```

브라우저에서 `http://localhost:4174`를 엽니다.

## GitHub Pages

1. 공개 저장소 `https://github.com/ko9ma7/tankstruct`의 `main` 브랜치에 소스를 둡니다.
2. 검증된 `dist/` 빌드를 `gh-pages` 브랜치 루트에 배포합니다.
3. `https://ko9ma7.github.io/tankstruct/`에서 하위 경로 자산과 새로고침을 확인합니다.
4. 데스크톱·모바일 계산, JSON/CSV, PNG/PDF 다운로드를 확인합니다.

모든 자산 경로는 상대경로라 저장소 하위 주소에서도 동작합니다. 로그인, 서버 DB, 비밀 API 키가 없어 GitHub Pages에 적합합니다.

## PNG·PDF 계산서

결과 상단의 `PNG 계산서` 또는 `PDF 계산서`를 누르면 전체 입력과 공식, 대입값, 결과, 단위, 근거, 경고가 한 문서로 저장됩니다. PDF는 내용이 길면 A4 여러 페이지로 나뉩니다. 계산서가 제작 승인을 의미하지는 않으며, 같은 입력을 다시 대입해 결과를 비교하기 위한 기록입니다.

- 적용할 법규·발주처 사양·설계 코드

- 충전·배출 횟수와 목표 설계수명
- 판재 등급·두께별 밀시트와 공급사 장기강도·크리프 자료
- 용접 방법, 용접사 자격, 이음 상세와 검사 방법
- 상부 프레임, 수평·수직 보강재의 실제 단면과 연결 상세
- 노즐, 맨홀, 배관, 교반기, 사다리와 보온재 하중
- 기초·지지대, 앵커, 지진·풍하중·운반 조건
- 누설 시험, 비파괴검사, 수압 시험과 품질 기록 계획
