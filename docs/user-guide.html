USER GUIDE · v0.2.0

입력부터 재검증 계산서까지

형상 입력, 보강안 비교, 공식 확인, 백업과 보고서 저장을 순서대로 안내합니다.

빠른 이동7단계결과 읽기저장제작 전 자료

빠른 시작

  1. 형상과 내부 치수사각·원통·호퍼를 고르고 액체가 실제로 차는 내부 치수와 액높이를 입력합니다.
  2. 액체와 온도비중, 설계온도를 입력합니다. 비중 1.0은 1,000 kg/m³입니다.
  3. 재료 물성 확인프리셋은 시작값입니다. 밀시트·공급사 데이터가 있으면 E, 기준 강도, 장기·이음·온도계수를 교체합니다.
  4. 판 두께와 보강측판·바닥판 두께, 수평 보강 줄 수와 수직 보강 개수를 입력합니다.
  5. 실제 프로파일 Z 입력프로파일 단면표의 강축/약축 방향을 확인하여 실제 단면계수 cm³를 넣습니다.
  6. 범위 밖 조건 표시밀폐, 외력, 부착물, 국부 지지는 숨기지 말고 체크합니다. 자동으로 전문 검토 대상이 됩니다.
  7. 계산서 저장재검증 계산식 표를 확인하고 PNG 또는 PDF를 저장합니다. 원자료는 JSON, 표 데이터는 CSV로 보관합니다.

결과 읽는 법

표시뜻다음 행동
목표 조건 이내입력한 단순 모델의 모든 적용 사용률이 100% 이하규격·용접·기초·노즐 검토로 이동
추가 검토 필요사용률 초과, 데이터 누락 또는 적용 범위 밖 조건경고 원인을 먼저 해소
근거 신뢰도 낮음온도·크리프·형상 등에 확인 자료가 부족공급사·규격 자료 확보
100% 이하는 제작 승인이라는 뜻이 아닙니다.화면 판정은 후보 두께·보강 격자를 비교하는 게이트입니다.

저장과 복원

  • 자동 저장: 같은 브라우저의 localStorage에 입력을 저장합니다.
  • JSON: 전체 프로젝트 입력과 재료 사용자값을 백업합니다. v0.1 파일도 읽어 v0.2 기본값으로 변환합니다.
  • CSV: 입력·결과뿐 아니라 각 계산식과 대입값을 행으로 저장합니다.
  • PNG/PDF: 프로젝트명, 시간, 입력 조건, 공식, 대입값, 단위, 경고를 한 계산서로 저장합니다.

실제 제작 전 받을 자료

  • 적용 규격·발주처 사양·설계수명
  • 액체 비중·농도·온도·부식성과 최고/최저 운전 조건
  • 재료 밀시트, 장기강도·크리프·약품 적합성
  • 보강 프로파일 단면표와 실제 배치 방향
  • 용접절차, 코너·보강재·바닥 접합 상세
  • 노즐·교반기·배관·플랫폼·사다리 하중
  • 풍·지진·운반·충격·기초·앵커·지지 조건
