# 한계와 전문 검토 전환 기준

다음 중 하나라도 해당하면 TankStruct의 통과 표시와 관계없이 전문 구조설계로 전환합니다.

## 즉시 전환

- 밀폐, 가압, 진공 또는 통기관 막힘 가능성
- 인화성, 폭발성, 독성, 고부식성 액체
- 법정검사·인증·보험·발주처 승인 대상
- 사람 통행로, 생산 핵심설비, 환경오염 위험 구역에 설치
- 지진, 풍하중, 옥외 설치, 차량·지게차 충돌 가능성
- 이동식 탱크, 운반 중 액체 슬로싱
- 교반기, 코일, 배관, 대형 노즐, 맨홀, 사다리, 플랫폼 부착
- 호퍼 경사판·전이부·배출구·지지 다리의 강도 판단

## 모델이 다루지 않는 현상

- 판의 실제 2방향 거동과 코너·용접부의 국부응력
- 보강재와 판의 합성작용
- 얇은 판·보강재의 국부좌굴과 비틀림
- 용접 잔류응력, 열변형, 용접 결함과 피로 균열
- PP·PE·PVC의 온도·시간·약품별 크리프와 응력균열
- 부식, 마모, 투과, UV, 열화, 세척제 영향
- 바닥판 굽힘, 기초 침하, 앵커와 지지대
- 내진·내풍·진동·충격·슬로싱
- 노즐·개구부 보강과 배관 반력
- 실제 피로수명

## “최적화”의 제한

화면의 비교안은 입력한 후보 두께와 보강 개수 안에서 응력·변형 사용률을 맞춘 조합입니다. 실제 원가, 재고, 절단 손실, 용접 공수, 검사, 운반, 설치, 유지보수까지 계산하지 않습니다.

PNG·PDF 계산서는 입력과 수식의 재검증 기록입니다. 보고서 저장 여부와 관계없이 밀폐·외력·부착물·국부 지지 조건은 전문 구조설계로 전환해야 합니다.

## 결과 검증 권장 순서

1. 입력 치수·비중·온도·액체 높이 확인
2. 적용 규격과 설계하중 목록 확정
3. 밀시트·공급사 장기강도·화학적합성 자료 확보
4. 판·보강재·용접·노즐·지지대 계산
5. 필요 시 비선형 FEA와 좌굴 해석
6. 제작도면·용접절차·검사계획 검토
7. 누설·수압·기능 시험과 기록 보존
