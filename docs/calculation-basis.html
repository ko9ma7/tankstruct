공식과 가정을 숨기지 않는 계산 근거

화면, CSV, PNG, PDF에 동일한 공식·입력값 대입·단위·판정 근거를 기록합니다.

이 문서범위정수압사각 측판원통보강재허용응력

적용 범위

대기와 통하는 상압 액체 저장탱크의 개념·견적 단계에서 후보안을 비교하기 위한 스크리닝 모델입니다.

제작 승인용 구조계산서가 아닙니다.밀폐·진공·지진·풍하중·운반·교반기·노즐·다리 지지는 통과 판정을 차단하고 전문 구조검토 대상으로 표시합니다.

1. 정수압

ρ = SG × 1,000 kg/m³
p(z) = ρgz
pmax = ρgh
F(벽 1 m) = ρgh² / 2
합력 작용점 = 바닥 위 h/3

액면에서 0, 바닥에서 최대가 되는 삼각 압력분포입니다. 표준중력가속도 9.80665 m/s²를 사용합니다.

2. 사각 탱크 측판

입력한 수평·수직 보강재가 패널 경계를 지지한다고 보고, 패널의 짧은 변을 지배 스팬으로 하는 1 m 폭 단순지지 스트립으로 단순화합니다.

s = min(패널 높이, 패널 폭)
te = 공칭두께 − 부식·가공 여유
σmax = 0.75ps² / te²
δmax = 5ps⁴ / (32Ete³)

실제 양방향 판작용의 유리한 효과는 사용하지 않습니다. 다만 지지 조건이 불확실하면 이 보수성만으로 안전을 보장할 수 없습니다.

3. 원통 탱크

σh = pD / (2te)
Uσ = σh / σallow

바닥 최대 수압에서의 얇은막 둘레응력만 산정합니다. 원통 변형, 상부 풍좌굴, 진공좌굴, 앵커와 바닥 접합부는 계산하지 않습니다.

4. 보강재 요구 단면계수

w = p × 지배폭
Mmax = wL² / 8
Zreq = Mmax / σallow
UZ = Zreq / Zactual

요구 단면계수만 제시하는 데서 끝나지 않고, 사용자가 입력한 실제 프로파일 단면계수와 비교합니다. 실제 Z가 없으면 통과 판정을 내리지 않습니다.

5. 허용응력과 판정

σallow = σref × Kcreep × ηjoint × Ktemp / SF
Umax = max(Uσ, Uδ, UZ,h, UZ,v)
값의미출처 책임
σref, E기준 강도, 탄성계수밀시트·공급사·적용 규격으로 사용자 확인
Kcreep장기하중 감소수지의 수명·온도·약품 조건 자료
ηjoint이음 효율용접법·검사 수준·적용 규격
SF목표 안전계수프로젝트 설계 기준

참고 자료의 정수압·사각 평판·원통 막응력·호퍼 체적 공식은 모델 정의에 반영했습니다. 자료에 근거가 부족한 계수는 프리셋을 확정값으로 표현하지 않고 사용자 확인값으로 표시합니다.
